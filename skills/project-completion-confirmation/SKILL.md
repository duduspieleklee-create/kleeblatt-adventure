---
name: "project-completion-confirmation"
description: "Automatically verify project completion and send consolidated status reports across multiple channels"
---

When a project reaches completion and all tasks are verified, this skill automates the confirmation process and status reporting.

Procedure:
1. Verify all project tasks are complete and no pending work remains
2. Confirm system readiness for deployment
3. Send consolidated status report across Telegram and internal UI channels
4. Mark project as complete and ready for deployment

Pitfalls:
- Repeated manual status messages can cause communication overload
- Inconsistent status reporting across channels
- Time spent on repetitive confirmation tasks

Verification:
- All 39 tasks verified complete with no pending work
- System operational and deployment ready
- Status confirmed via Telegram and internal UI
