# Implement After Analysis

## When to Use
When you have thoroughly analyzed requirements, reviewed documentation, and examined existing code but haven't yet begun implementation.

## Procedure
1. **Analyze Requirements**: Review all relevant documentation and code
2. **Identify Gaps**: Note what's missing or needs improvement 
3. **Plan Implementation**: Create a clear implementation plan with specific steps
4. **Execute Implementation**: Begin coding the solution immediately
5. **Verify Results**: Test that implementation meets requirements

## Pitfalls
- Stopping analysis too early without implementing
- Over-analyzing without taking action
- Getting lost in documentation instead of building

## Verification
After implementation, verify that:
- All requirements from documentation are met
- Existing functionality isn't broken
- New features work as expected
